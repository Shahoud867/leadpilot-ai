# Five-minute customer demonstration

Before presenting: start the app, sign in as `owner@margalla.example` / `Demo@2026!`, open Demo Lab and **Reset demo**, typing `RESET SYNTHETIC DATA`. Reset preserves the other business. All examples are synthetic; this is evidence of working process control, not proven conversion improvement.

| Time | Exact action | What to explain |
|---|---|---|
| 0:00–0:35 | Overview → select Last 30 days, optionally filter source | The numbers reconcile to stored inquiries, outcomes and deadlines. No live client performance is claimed. |
| 0:35–1:20 | Demo Lab → **A new inquiry arrives** → **Inspect lead 1** → Decisions | Capture validates, qualification explains each factor, allocation compares alternatives, follow-up sets an SLA task. All four decisions persist. |
| 1:20–2:10 | Close lead → **The missed admission** → Inspect lead → Decisions | Four virtual hours elapsed. Recovery identifies the original deadline and owner; the missed SLA stays in history. |
| 2:10–2:45 | Close lead → **The manager has context** → Inspect lead → Timeline | Manager overrides are explicit, capacity-checked and audited with before/after ownership and a reason. |
| 2:45–3:30 | Close lead → **From reply to appointment** → Inspect lead → Messages, then Timeline | Outbound is simulated, consent checked, customer reply recorded, qualification confirmed and an appointment booked. No WhatsApp account is needed. |
| 3:30–4:10 | Close lead → **A verified conversion** | The persisted won count increases by one and synthetic won value increases PKR 65,000. Verification is mandatory; an agent score cannot close a deal. |
| 4:10–4:45 | **20 inquiries, one fair plan** → inspect comparison | Same input batch, conventional greedy baseline vs constrained optimization. Explain any fairness relaxation or unassigned work; never equate utility gain with actual sales uplift. |
| 4:45–5:00 | Analytics → funnel and SLA | Ask which real baseline and supervised pilot would establish value. ROI inputs are assumptions, not sales promises. |

Extra proof points if asked:

- Lead inbox → Import CSV → Validate CSV → Confirm import. The supplied sample has two identical contacts; one lead is created, one duplicate audited, no silent overwrite.
- Demo Lab → Consent comes first → inspect Tasks/Timeline. The approved simulated message is suppressed after opt-out.
- Demo Lab → A connector times out → Follow-ups → queue shows retry → Demo Lab advance 2 minutes → queue completes once.
- Sign out → Estates viewer account. Data and access change; scenario execution and workflow writes are disabled and denied server-side.
- New lead → simulate reply → Move stage → qualified → appointment (future time) → won (verified positive value). Invalid skips are rejected with useful errors.

If the virtual clock is outside adviser shifts or the team is full, an inquiry may remain unassigned. This is intended. Reset before a timed presentation, or adjust availability in Assignment board with an auditable configuration change.
